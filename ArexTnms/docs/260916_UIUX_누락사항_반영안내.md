# TNMS UI/UX 기획 누락사항 반영

## 적용 순서

1. 압축파일을 프로젝트 루트에 덮어씁니다.
2. `db/AREX_TNMS_MENU_URL_MIGRATION.sql`을 재실행합니다.
3. `db/AREX_TNMS_UIUX_INITIAL_DATA_MIGRATION.sql`을 재실행합니다.
4. Eclipse Maven Update 후 Tomcat을 재기동합니다.
5. 브라우저 캐시를 강력 새로고침합니다.

## 대시보드 상태 판정

- 장애: `CRITICAL`
- 통신단절: `CNTN_YN='N'` 또는 마지막 수집시각이 설정값을 초과함
- 주의: `CAUTION`, `WARNING`
- 정상: `NORMAL`
- 역사 대표 상태 우선순위: 장애 > 통신단절 > 주의 > 정상
- 통신단절 판정시간은 설정 화면의 `통신단절 판정시간`에서 변경하며 기본값은 5분입니다.

초기 화면 데이터는 VMS와 SCADA에서 김포공항이 장애, 계양이 주의로 표시되도록 구성했습니다.
`UIUX-SAMPLE-*` 초기 화면 데이터는 수집기가 갱신하지 않는 시연용 자료이므로 시간 경과 판정에서 제외하며, 실제 장비 데이터에만 마지막 수집시각 기준을 적용합니다.

## 계정관리 통합

- 운영관리 메뉴의 `사용자 계정 설정`과 `계정 신청 현황`을 `계정관리`로 통합했습니다.
- 기존 `/user/applications.do` 접근은 통합 계정관리 화면으로 이동합니다.
- 신청 조회·상세·승인·반려 권한은 사용자 계정 관리 권한을 사용합니다.

## 설정 화면

- 페이지당 목록 수
- 비밀번호 변경주기
- 대시보드 갱신주기
- 장애 팝업/사운드 등급
- 55인치 표준모드
- 통신단절 판정시간
- 장애/장애조치 푸시 알림
- 공통코드 상세 등록·수정
- 이벤트 등급명·색상·사용여부 저장
