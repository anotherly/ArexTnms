# 2026-09-14 TNMS UI/UX 및 DB 연동 적용 안내

## 반영 내용

- 계정신청 이메일을 선택 입력으로 변경
- 메인 대시보드에 기본모드/확장모드 추가
  - 기본모드: 기존 전체 구성 표시
  - 확장모드: 하단 장애 분석 영역과 화면 전환 점을 숨기고 지도/시스템 현황을 확대 표시
- 역사형 지도에서 인천공항2터미널 역명이 무인국사 영역에 가려지지 않도록 역명 위치와 하단 영역 높이 조정
- 대시보드 KPI·역사 현황을 `link_sys_info`, `stn_info`, `eqpmnt_info`, `eqpmnt_stts`에서 조회
- 5종 설비 화면 장비목록 및 상태를 실제 DB에서 조회
- 설비 공통 등록·수정·미사용 처리 기능 추가
- 작업로그 목록·상세 조회를 `job_log`와 연동
- 공통코드/UI 설정 조회·저장을 `com_cd_group_info`, `com_cd_info`, `ui_stng_info`와 연동
- 장애현황 보고서 집계를 `dsblty_info`, `eqpmnt_info`, `link_sys_info`와 연동
- 공통 필드는 기존 `BaseVO`와 신규 `MonitoringBaseVO`를 상속해 사용
- 공통 API, HTML 이스케이프, 권한 버튼, 모달, 테이블 처리는 기존 `tnms-common.js` 함수를 재사용

## DB 적용 순서

1. 기준 DB가 첨부된 `arex_tnms 260914.sql` 상태인지 확인
2. `db/AREX_TNMS_UIUX_INITIAL_DATA_MIGRATION.sql` 실행
3. 애플리케이션 재빌드 및 WAR 재배포

초기 데이터 마이그레이션은 기존 화면의 가데이터를 실제 조회 구조에서 확인할 수 있도록 다음 데이터를 비파괴 방식으로 추가합니다.

- 지도 외 무인 감시지점 7곳
- `UIUX-SAMPLE-*` 관리번호를 사용하는 5종 설비 샘플 장비 10대
- 샘플 장비 상태 및 CPU/메모리 현재값
- 대시보드·보고서 확인용 샘플 장애

같은 마이그레이션을 다시 실행해도 고유 관리번호와 장애번호 기준으로 갱신되며 운영 장비를 삭제하지 않습니다.

## 제외 범위

- 일반/다크 테마 전환은 반영하지 않음
- 장애관리 화면의 기존 HTML/JavaScript는 수정하지 않음
- 성능관리 화면의 기존 HTML/JavaScript는 수정하지 않음
